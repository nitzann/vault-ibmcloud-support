Vault Agent renewal loop: After token issuance the Agent monitors the credsFound channel. When pollForCRToken() detects a new CR token it signals via the channel, triggering re-authentication before the current Vault token expires. Shutdown() closes both stopCh and credsFound to terminate the goroutine cleanly.
